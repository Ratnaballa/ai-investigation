# AI Investigation Assistant

## Features
- AI Chatbot
- Legal Recommendation
- Evidence Relationship Graph
- Case Management
- Reports Generation
- Dark/Light Theme

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- FastAPI
- MongoDB
- FAISS
- Grok API

## Installation

Frontend:
npm install
npm run dev

Backend:
pip install -r requirements.txt
python run.py
